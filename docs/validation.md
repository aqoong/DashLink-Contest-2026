# DashLink 검증 결과

기준일: 2026-11-15 · 제출 버전: **0.3.8-mvp** (versionCode 10) · applicationId: `ai.pleos.contest.dashlink`

DashLink는 **정차 상태에서 앱을 전경에 열고 시험하는 Pleos Connect MVP**다. 운전자가 응답할 수 없고 통신도 끊긴 상황에서 조명 SOS를 마지막 도움 요청 수단으로 사용하는 흐름을 구현했다. 현재 사고 상황은 사용자가 시작하는 모의테스트로 재현한다. 상시 사고 감시, 운전자 행동불능 진단, 실제 긴급 신고를 제공하는 제품으로 검증한 것은 아니다.

## 시험 환경

| 항목 | 환경 |
| --- | --- |
| Pleos 에뮬레이터 | Connect 2.1.0 / Android API 34 / ARM64, Cold boot |
| 기본 디스플레이 | 2560×1440px, 160dpi, 가로 화면 |
| 좁은 창 시험 | 이전 버전에서 374dpi로 Cold boot한 뒤 기본 디스플레이의 창 분할. 앱 영역 약 353×400dp |
| 차량·위치 SDK | Vehicle 2.3.2 / FusedLocation 1.1.3 |
| 빌드 | JDK 17 / Gradle 8.13 / AGP 8.11.1 / Kotlin 2.2.20 |
| Android 설정 | minSdk 28 / compileSdk·targetSdk 34 / Build Tools 36.0.0 |

영상은 1920×1080으로 인코딩한 자료이며 에뮬레이터의 원래 화면 규격과 다르다. 실행·설치 방법은 [README](../README.md)에 있다.

## 에뮬레이터에서 따라 해보기

1. Pleos AVD를 **Cold boot**하고 release APK를 설치한다. Park·속도 0 및 플랫폼 제한 해제 상태에서 앱을 전경으로 연다. 앱은 CarUxRestrictions를 확인할 수 없거나 제한이 활성화되면 동작을 제한한다.
2. 연락처는 건너뛰거나 가상 시험 연락처를 등록한다. 119 설정은 실제 발신 없이 모의 결과만 바꾼다. 위치는 별도로 동의한 경우에만 조회한다.
3. 홈에서 각 차량 부위를 눌러 조회값과 미지원·오류를 구분한다. Virtual Console에서 문 또는 EV 충전량을 변경한 후 새로고침으로 반영 여부를 확인한다.
4. 기본 **화면 미리보기**에서 OK·고마워·미안해를 누른다. 버튼 아래 점·선의 진행과 빨간 중지 상태를 확인하고 같은 버튼으로 중지한다. 이 모드에서는 SDK 조명 쓰기를 보내지 않는다.
5. **설정 → 에뮬레이터 조명**에서 지원 조명을 선택하고 필요한 제어 권한을 허용한다. 홈 메시지 재생 후 원래 스위치 복귀 결과를 확인한다. 사용할 수 있는 조명이 없으면 미리보기로 확인한다.
6. **설정 → 모의테스트 → 통신이 끊긴 사고**로 진입한다. 이 시험의 출력 방식을 다시 선택하고 시작한다. 10초 안에 취소하거나, 응답하지 않고 SOS 3회와 모의 연락 실패 결과를 확인한다.
7. SDK 메시지 재생 중 Virtual Console에서 Drive·20km/h로 전환해 제한과 중단을 확인한다. Park·0km/h로 돌아온 뒤 복구가 필요하면 **조명 복구 → 정차 상태에서 복구**를 누른다. 원래 스위치 기록, 권한·연결, 안전 상태와 별도 재조회 결과가 확인되어야 추가 출력이 가능하다.

복구 기록이 없거나 요청이 끝나지 않았거나 재조회가 일치하지 않으면 잠금을 유지한다. 잠금을 없애기 위해 앱 데이터를 지우거나 플랫폼 제한을 해제하는 절차는 사용하지 않는다. 개인정보 삭제도 조명 안전 잠금을 해제하지 않는다.

## 데이터와 남은 검증

연락처는 선택 사항이며 기기의 Android Keystore를 이용해 암호화 저장한다. 가상 연락처의 저장·번호 마스킹·재실행 후 보존·삭제를 0.3.0에서 확인했다. 위치는 전경 세션에서 사용하며 앱 이탈 시 동의·구독·좌표를 정리하도록 구현했다. 이 수명주기의 모든 조합을 제출 버전 AVD에서 다시 시험하지는 않았다.

실차, 실제 충돌·에어백 전개·운전자 행동불능, 사고 후 전원 유지, 장시간·백그라운드 감시, 물리 조명 파형·수동 스위치 우선권, 실제 119·보호자 연동, App Market 승인은 미검증이다. CarUxRestrictions나 안전 잠금을 우회하지 않았다.
